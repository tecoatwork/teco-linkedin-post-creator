| 主题 | 组织方式 | 必须核对 |
| --- | --- | --- |
| 工厂/发货/质检 | 一个现场动作 → 控制什么问题 → 对交付的意义 | 照片与事实是否对应，不能从一张设备照片推出产能、交付率或认证 |
| 行业趋势 | 有日期范围的变化 → 可能原因 → 买家应采取的检查/行动 | 数据原始来源、国家/品类/期间/单位；出口额与出口量不同，相关性不等于因果 |
| 客户案例 | 客户情境 → 遇到的问题 → 真实协作/改进 → 已知结果或经验 | 结果与公开身份是否获确认，不能虚构合作、评价或改善百分比 |
| 产品科普 | 采购/产品角色的问题 → 原理/参数/取舍 → 如何比较或验证 | 材料性能与系统效果、适用条件、技术证据 |
| 产品卖点/差异化 | 特性 → 在什么场景形成优势 → 买家意义 → 证据/限制 | 优势是否基于公平比较；没有证据不声称行业第一或优于所有竞品 |
| 公司研发/动态 | 实际进展 → 解决的问题 → 下一步或客户价值 | 区分研发中、样品验证与量产能力，不把实验设想写成成果 |

其他主题按读者问题选择结构，不机械强套这六类。

避免假装作者参加了展会、拜访了客户或拥有未提供的经历。匿名案例仍需要真实事实；缺乏案例材料时可以写明确标注的假设场景，但不得当成案例发布。客户标识、员工肖像、订单和物流标签是否可公开不明时，先提示处理或使用不含这些信息的素材。

结尾服务于帖子目标：知识类可以给一个检查建议，案例类可以问一个具体业务问题，产品类可以提供样品/资料入口。不要同时要求点赞、转发、评论、关注和私信。
